# สำรองก่อนปรับโทนเทาถ่านอมทราย — 20 ตุลาคม 2026

เก็บซอร์สก่อนปรับสีและรายละเอียดหน้าภายใน โดยคงโครงหน้าและระบบเดิม หน้า Login ใช้สีเดิม ไม่มี `.env` หรือข้อมูลผู้ใช้ในไฟล์สำรอง

ตรวจสอบรายการที่จะย้อนกลับ จากโฟลเดอร์ QCheck:

```bash
python3 .local-backups/before-warm-graphite-2026-10-20/restore.py --check
```

คืนธีมเดิมก่อนปรับเทาถ่านอมทราย:

```bash
python3 .local-backups/before-warm-graphite-2026-10-20/restore.py --apply
```

สคริปต์ตรวจ SHA256 ของไฟล์ก่อนคืนค่า และหยุดหากมีการแก้ไฟล์เหล่านี้ภายหลังเพื่อไม่เขียนทับงานใหม่ คืนเฉพาะไฟล์ที่เกี่ยวกับธีม พร้อมลบ `src/app/app-theme.css` ที่เพิ่มมา หลังคืนค่าให้รีเฟรชหน้าเว็บ

`originals.tar.gz` และ `manifest.json` เก็บต้นฉบับ ส่วน `applied-manifest.json` ระบุไฟล์ที่แก้จริงและ SHA256 ของงานที่ส่งมอบ
