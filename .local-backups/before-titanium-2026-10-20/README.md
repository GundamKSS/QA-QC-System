# สำรองก่อนเปลี่ยนธีม Titanium — 20 ตุลาคม 2026

สำรองไฟล์หน้าภายในก่อนเปลี่ยนสีเป็นไทเทเนียมอ่อนและเมนูกันเมทัล รวมเฉพาะซอร์สโค้ดที่เกี่ยวข้อง ไม่มี `.env` รหัสผ่าน หรือข้อมูลผู้ใช้ในไฟล์สำรอง

ตรวจสอบไฟล์สำรองและดูรายการที่จะคืนค่าก่อน โดยรันจากโฟลเดอร์ QCheck:

```bash
python3 .local-backups/before-titanium-2026-10-20/restore.py --check
```

กลับไปใช้ธีมเดิม:

```bash
python3 .local-backups/before-titanium-2026-10-20/restore.py --apply
```

ถ้าไม่ระบุคำสั่ง สคริปต์จะตรวจสอบอย่างเดียว ไม่เปลี่ยนไฟล์ หลังคืนค่าให้รีเฟรชหน้าเว็บ

`originals.tar.gz` เก็บไฟล์เดิม และ `manifest.json` เก็บ SHA256 สำหรับตรวจสอบความครบถ้วน ส่วน `applied-manifest.json` บันทึกไฟล์ที่เปลี่ยนจริงและ SHA256 ของธีมที่ส่งมอบ สคริปต์ตรวจทั้งหมดก่อนเขียน คืนเฉพาะไฟล์ธีมตามรายการนี้ และลบไฟล์ `src/app/app-theme.css` ที่เพิ่มเข้ามา หากมีการแก้ไฟล์เหล่านี้ภายหลัง สคริปต์จะหยุดเพื่อไม่เขียนทับงานใหม่ สามารถรันซ้ำหลังคืนค่าแล้วได้

ขอบเขตรวมหน้า Home, Master, ผู้ใช้หน้างาน, การแจ้งเตือน, บัญชี/เพิ่มเติม, โครงหน้าและเมนู รวมถึงตัวเลือกหน้าตาของปุ่มออกจากระบบที่ใช้ร่วมกับหน้า Login โดยค่าเริ่มต้นของปุ่มในหน้า Login ยังคงเดิม ไม่แก้ระบบยืนยันตัวตนหรือฐานข้อมูล

สำหรับทดลองคืนค่าในสำเนาชั่วคราว สามารถเพิ่ม `--root /absolute/path/to/temporary-copy` ได้ คำสั่งนี้ยังใช้รายการไฟล์และลายเซ็นจากโฟลเดอร์สำรองชุดนี้ และไม่ยอมเขียนออกนอกโฟลเดอร์ปลายทางหรือผ่าน symbolic link
