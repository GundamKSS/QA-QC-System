> 20 ต.ค. 2026 · ผู้ใช้ OK storyboard + P1–P5 ตามค่าตั้งต้น → **สร้างแล้ว** และตรวจใน browser (memory store, มือถือ 375 px + laptop) · ยังไม่ทดสอบกับ SQL Server จริง · ต่อยอดจาก Wireframe S10 / S12 และ FR-PLAN-10, 11, 12, 13, 16, 17
> ที่ต่างจากร่างเล็กน้อย: เรียงตามวันที่เปิด (ตั้งต้น) / เลขแผน น้อย→มาก / กำหนด 90 วัน ใกล้สุดก่อน · วันที่แสดงเป็น ค.ศ. (D15) · บนมือถือกล่องสรุปอยู่บนสุด · สถานะ ON_HOLD แสดงเป็น "QA พักล็อต" (ไม่มีในตาราง 03 §2.1) · ยกเลิกแผนที่มีผลตรวจแล้วต้องเป็น QC/QA Head (BR-13)

> สไตล์เดียวกับ `/plans/new` และหน้าข้อมูลหลัก (carbon / ti / ember, ตาราง `rounded-xl border-carbon-700`)
> **หมายเหตุ 26 ต.ค. 2026:** Server Actions (`…Action`) และไฟล์ `plans/actions.ts` ที่อ้างในเอกสารนี้ถูกแทนที่ด้วย API routes แล้ว — ตารางแมปชื่อเดิม → route ใหม่อยู่ใน [19 §3](19-api-routes-plan.md#3-แผนที่-api-และสถานะ) ส่วนกติกาธุรกิจ ข้อความ และสิทธิ์ในเอกสารนี้ไม่เปลี่ยน

## 3. `/plans/[id]` — รายละเอียดแผน
```
← รายการแผน
QP-2610-0001  [ยังไม่ตรวจ]  [ยังไม่เริ่ม]                    [ยกเลิกแผน]
XM2525 · ปั๊มลมโรตารี่ 1/4HP 25L
[ ข้อมูล | ใบงาน | ประวัติ ]                                 ← แท็บผ่าน ?tab=
┌ หัวเอกสารรับเข้า ─────────────┐ ┌ สรุป ───────────────────┐
│ Invoice INV-2610-001          │ │ QC ตรวจแล้ว / ต้องตรวจ    │
│ Vendor  Zhejiang Hongyou      │ │      0 / 35  ▓░░░░░       │
│ วันที่ Invoice 01/10/2026     │ │ ปัดขึ้น(350 × 10%)        │
│ SKU 3 · เปิดแผนแล้ว 2 [ดู]    │ │ กำหนด 90 วัน 30/12/2026   │
├ ส่วนแผน ──────────────────────┤ │ เหลือ 71 วัน              │
│ Model / Brand / ประเภทปั๊ม     │ │ ล็อต 350 · เรียกเข้าแล้ว 0 │
│ Checklist QC / QA (ผูกตอนเปิด) │ │ คงเหลือ 350                │
│ ล็อต · วันที่รับเข้า · ผู้ผลิต    │ │ ☐ รอของ (ของยังมาไม่ครบ)   │
│ หมายเหตุ · เปิดโดย … เมื่อ …    │ └──────────────────────────┘
└───────────────────────────────┘
```
- **ข้อมูล**: ตามภาพ — แผนอื่นใน Invoice เดียวกันเป็นลิงก์ (ภาพรวมราย Invoice เบื้องต้น FR-PLAN-14)
- **ใบงาน**: ยอดล็อต / เรียกเข้าแล้ว / คงเหลือ / ตรวจสะสม (ตอนนี้เป็น 0) + ข้อความ "เปิดใบงานต่อครั้งที่เรียกเข้า — มาในขั้น 7"
- **ประวัติ**: จาก `plan_status_history` — เปิดแผน, ยกเลิก (เวลาไทย, ผู้ทำ, เหตุผล)
- **ยกเลิกแผน** (BR-13): ตอนนี้ยังไม่มีผลตรวจ → ผู้มีสิทธิ์ `plan-open` ยกเลิกได้ ต้องใส่เหตุผล · ยืนยันอีกครั้ง · หลังยกเลิกเปิด Invoice + Model เดิมใหม่ได้ (BR-01 ไม่นับแผนที่ยกเลิก) · บันทึก audit + history
- **รอของ** (FR-PLAN-17): ติ๊ก/เอาออก → บันทึกทันที + audit

## 6. ต้องตัดสินใจ (ค่าตั้งต้นถ้า OK)
| # | คำถาม | ค่าตั้งต้น |
|---|---|---|
| P1 | แท็บที่ยังไม่มีข้อมูล (รายเครื่อง, Rework, QA, Report) แสดงไหม? | **ไม่แสดง** — มีแค่ ข้อมูล / ใบงาน / ประวัติ แล้วเพิ่มเมื่อโมดูลนั้นมา |
