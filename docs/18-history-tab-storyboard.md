# 18 — Storyboard: แท็บ "ประวัติ" `/history` แทนแท็บแจ้งเตือนด้านล่าง

> 21 ต.ค. 2026 · ผู้ใช้ OK (H1–H3 ตามค่าตั้งต้น) → **สร้างแล้ว** (ทดสอบด้วยเทสต์; ยังไม่ได้ดูใน browser และยังไม่ลองกับ SQL Server จริง) · ผู้ใช้เลือกใช้ "ประวัติ" แทนแท็บแจ้งเตือน (กระดิ่งมุมขวาบนเป็นทางเข้าแจ้งเตือนทางเดียวแล้ว และสั่นเป็นระยะเมื่อมีที่ยังไม่อ่าน — ทำแล้ว)
> ข้อมูลที่มีตอนนี้: ใบงาน (`work_orders`) + ผู้ตรวจ — ยังไม่มีผลตรวจรายเครื่อง จึงเป็น "ประวัติใบงาน" ไปก่อน แล้วเพิ่ม "เครื่องที่ตรวจ" เมื่อมีโมดูลตรวจ

## 1. แท็บล่างหลังเปลี่ยน (ตอนทำจริงเป็น 5 แท็บ: หน้าหลัก · … · ประวัติ · เพิ่มเติม — แท็บแจ้งเตือนเดิมถูกแทนที่)
| บทบาทหลัก | แท็บ |
|---|---|
| QC Inspector | งานของฉัน · สแกน · **ประวัติ** · เพิ่มเติม |
| QA Inspector | คิว QA · สแกน · **ประวัติ** · เพิ่มเติม |
| QC Head | แผน · งาน · **ประวัติ** · เพิ่มเติม |
| QA Head | แผน · คิว QA · **ประวัติ** · เพิ่มเติม |
| บทบาทอื่น (Admin, Master Admin, …) | แท็บที่ 3 เดิม (แจ้งเตือน) → **ไม่เปลี่ยน** เพราะยังไม่มีประวัติของบทบาทเหล่านี้ |

เมนูซ้ายบน laptop คงรายการ "แจ้งเตือน" ไว้ · ปรับ docs/09 §2 และเทสต์ nav ให้ตรงกัน

## 2. หน้า `/history` (ทุกบทบาทที่มีแท็บนี้เข้าได้)
```
ประวัติ
[ทั้งหมด | ใบงานที่ส่งแล้ว | ยกเลิก]         ช่วงเวลา [30 วันล่าสุด ▼]
┌──────────────────────────────┐
│ QP-2610-0001-1       ปิดแล้ว  │  ← แตะ = รายละเอียดใบงาน (QC Head/QA Head → หน้าแผน)
│ XM2525 · INV-500             │
│ เรียกเข้า 200 · 20/10/2026    │
│ ต้องตรวจ 20 · ตรวจแล้ว 24     │
│ ร่วมกับ: ปรีชา ทองดี          │
└──────────────────────────────┘
```
- **QC Inspector:** เฉพาะใบงานที่ตัวเองอยู่ในรายชื่อ และไม่ใช่ "กำลังทำ" (ส่งแล้ว / ปิด / ยกเลิก) — กำลังทำอยู่ที่ "งานของฉัน"
- **QC Head / QA Head:** ทุกใบงานที่ไม่ใช่ "กำลังทำ" + ตัวกรอง "ของฉัน" · QA Head ดูอย่างเดียว
- เรียงใหม่สุดก่อน · 50 รายการต่อหน้า · ตัวกรองอยู่ใน URL เหมือนหน้ารายการแผน
- มือถือเป็นการ์ด · laptop เป็นตาราง
