# Pass 7 — เครื่องส่วนกลาง: หมดเวลาเมื่อไม่ใช้งาน (ตัด PIN แล้ว)

> ⚠️ **DEC-11 ถูกกลับโดย DEC-12 (19 ต.ค.): กลับมาใช้ PIN สำหรับผู้ใช้หน้างาน — ดู [12](12-field-users-pin-plan.md)** · เอกสารนี้ยังใช้ได้สำหรับส่วน idle timeout และ checklist ทดสอบมือถือ
> สถานะเดิม: DEC-11 ไม่ใช้ PIN · เข้าใช้ด้วย **รหัสพนักงาน + รหัสผ่าน** (ระบบกลาง TRW) อย่างเดียวทุกเครื่อง
> ที่มา: FR-AUTH-05 ([02](02-spec-functional.md)), DEC-09/DEC-11 ([04](04-spec-technical.md)), [08](08-central-auth-plan.md)
> ผลต่อ Pass 6: ค่า Lighthouse มือถือที่มี 3D (63) ยอมรับไว้ก่อน รอทดสอบเครื่องจริง — checklist อยู่ §4

## 1. ขอบเขตหลังตัด

| เดิม | ตอนนี้ | เหตุผล |
|---|---|---|
| หน้าตั้งรหัสใหม่ครั้งแรก | ตัด | DEC-09: รหัสผ่านเป็นของระบบกลาง (รอ G4 ยืนยัน) |
| PIN + หน้าเลือกผู้ใช้ (`/switch-user`) | **ตัด** (DEC-11) | เจ้าของโครงการเลือกให้ใช้แค่ username/password — ลดความเสี่ยง PIN ข้ามการตรวจสิทธิ์ (เดิม R1) และไม่ต้องมีที่เก็บ hash PIN |
| หมดเวลาเมื่อไม่ใช้งาน เครื่องส่วนกลาง 30 นาที / ส่วนตัว 12 ชม. | **คงไว้** | FR-AUTH-05 |

คนที่ใช้เครื่องร่วมกัน: ออกจากระบบ (หรือหมดเวลา) แล้ว login ด้วยรหัสตัวเอง — ร่างของแต่ละคนยังแยกกัน (ผูกกับโมดูลออฟไลน์)

## 2. ที่ทำแล้ว (logic ล้วน, 160 tests ผ่าน)

- `lib/config/auth.ts`: `devices.personal` (ไม่หมดเวลา) / `devices.shared` (30 นาที เตือนก่อน 60 วินาที)
- `lib/auth/idle.ts`: `idleState()` → active / warning / expired และ `nextIdleCheckMs()` — รับเวลาเป็นพารามิเตอร์ ใช้ได้ทั้ง server และ client
- ลบโค้ด PIN ที่เคยทำไว้ชั่วคราว (`pin.ts`, `reset` ใน `attempts.ts`) แล้ว

## 3. ที่ยังไม่ทำ

1. **ต่อ idle เข้ากับ UI/session** — ตัวจับเวลาฝั่ง client + เตือน "จะออกจากระบบใน N วินาที" + ปุ่มอยู่ต่อ; server ต้องเรียก `idleState` ทุกคำขอ ไม่เชื่อตัวจับเวลา client อย่างเดียว
2. **รู้ว่าเครื่องเป็น "ส่วนกลาง"** — ต้องให้ Admin ลงทะเบียนเครื่อง (S24) ซึ่งต้องมีที่เก็บทะเบียนฝั่ง server (ผูก DEC-01/ชั้นข้อมูล) · ถ้าไม่มีเครื่องส่วนกลางเลย (E3 ยังไม่มีคำตอบ) ข้อนี้ตัดทิ้งทั้งหมดได้
3. E12: ออกจากระบบตอนมีงานรอซิงค์บนเครื่องส่วนกลาง — กำหนดเมื่อทำโมดูลออฟไลน์
4. G4: ระบบกลางทำล็อก/บังคับเปลี่ยนรหัสหรือไม่ — ยังรอ IT

## 4. รอทดสอบมือถือจริง (ของ Pass 6 — ให้ผู้ใช้ลอง)

เปิดหน้า login บน iPhone Safari และ Android Chrome จริง แล้วดู:
- [ ] ฟอร์มกดได้ทันที ก่อน 3D ขึ้น · 3D ขึ้นเองภายในไม่กี่วินาที ไม่ค้างตอนพิมพ์
- [ ] เลื่อนหน้าได้ปกติเมื่อปัดบนโมเดล · ลากหมุนโมเดลไม่ดึงโฟกัสจากฟอร์ม
- [ ] คีย์บอร์ดเปิดแล้วฟอร์มไม่ถูกบัง (ช่องรหัสผ่าน + ปุ่ม)
- [ ] ตัวอักษรไทยในหัวข้อวรรณยุกต์ไม่โดนตัด · แสดงครบหลังเผยคำ
- [ ] โหมดประหยัดพลังงาน/Save-Data → ขึ้นภาพ poster แทน 3D
- [ ] เครื่องร้อน/ลื่นไหลแค่ไหนหลังเปิดค้างหน้า 1–2 นาที (บอกรุ่นเครื่อง)
